# APEX Vision AI v2.2 AI Geometry Lab

This branch is an isolated research/benchmark version based on the v2.1 production-hardening branch. It does not modify `feature/v2.1-production-hardening`.

## Goal

Improve floor calculation, physical tile scale, perspective projection, and furniture occlusion by moving from relative image depth + 2D polygon fitting toward metric 3D scene geometry.

## Pipeline

```text
Room image
  -> GroundingDINO floor/object detection
  -> SAM3 concept segmentation
  -> Metric3Dv2 OR UniDepthV2 metric geometry
  -> robust 3D floor-plane fitting
  -> depth/normal gated floor-mask refinement
  -> floor polygon + homography
  -> existing tile renderer
```

## Depth candidates

### Metric3Dv2

Default v2.2 depth provider. It exposes metric depth and surface normals and is used for the first production-quality geometry benchmark.

### UniDepthV2

Optional benchmark provider. It exposes metric depth, 3D points, camera intrinsics, and confidence. It is useful for comparing direct camera-aware 3D reconstruction against Metric3D.

## Segmentation

SAM3 image concept segmentation is used for single-image floor/object concepts. SAM3.1's released multiplex checkpoint is a video/multi-object tracking model and is therefore not loaded into the image model. The v2.2 branch reserves SAM3.1 multiplex for a future video/sequence path.

## Runtime

Use the isolated launcher:

```powershell
.\start-v2.2.ps1
```

or benchmark UniDepth:

```powershell
.\start-v2.2.ps1 -Depth unidepth
```

Default port is `8010`, keeping v2.1 on port `8000`.

Set `APEX_V22_DEVICE=cuda` to require CUDA. `auto` selects CUDA when available.

## Important model/runtime requirements

SAM3 upstream currently documents Python 3.12+, PyTorch 2.7+, and a CUDA 12.6+ GPU for the released setup. The SAM3.1 checkpoint is gated on Hugging Face and requires access approval.

UniDepthV2 is retained as a benchmark candidate only until its upstream CC BY-NC 4.0 license is reviewed for the intended commercial use.

Metric3D is BSD-2-Clause licensed upstream and is the preferred first candidate for a commercial production path, subject to the normal dependency/license review.

## Non-negotiable isolation rule

No v2.2 AI provider is enabled by the v2.1 production launcher. The production branch remains unchanged and continues to use its existing Heavy-AI stack.
