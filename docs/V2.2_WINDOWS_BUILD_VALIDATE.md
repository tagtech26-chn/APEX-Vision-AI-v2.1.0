# v2.2 Windows build and validation

## 1. Pull the isolated branch

```powershell
git fetch origin
git checkout feature/v2.2-ai-geometry-lab
git pull origin feature/v2.2-ai-geometry-lab
```

Do not merge this branch into v2.1 yet.

## 2. Create the isolated Python environment

```powershell
py -3.12 -m venv .venv-v22
.\.venv-v22\Scripts\Activate.ps1
python -m pip install --upgrade pip "setuptools<82" wheel
pip install -r requirements.txt
```

`setuptools<82` is intentional because SAM3 currently has environments where `pkg_resources` is still imported during startup.

## 3. Check the NVIDIA driver before installing Torch

```powershell
nvidia-smi
```

The v2.2 SAM3 path is intended for an NVIDIA CUDA GPU. If CUDA is available, install a CUDA-enabled PyTorch build in `.venv-v22`; do not modify the v2.1 environment.

Example for the CUDA 12.6 wheel line:

```powershell
pip install torch==2.7.0 torchvision torchaudio --index-url https://download.pytorch.org/whl/cu126
```

Then verify:

```powershell
python -c "import torch; print(torch.__version__); print('CUDA:', torch.cuda.is_available()); print(torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'CPU')"
```

## 4. Install SAM3 separately in v2.2

```powershell
pip install git+https://github.com/facebookresearch/sam3.git
```

SAM3 checkpoint access must be approved on Hugging Face and authenticated before the first model smoke test.

## 5. Install Metric3Dv2 dependencies

Metric3D upstream provides the complete dependency set in `requirements_v2.txt`. Install that dependency set in `.venv-v22` from an upstream Metric3D checkout rather than copying it into the production environment.

```powershell
git clone https://github.com/YvanYin/Metric3D.git .\third_party\Metric3D
pip install -r .\third_party\Metric3D\requirements_v2.txt
```

The APEX provider uses the official PyTorch Hub model:

```text
yvanyin/metric3d -> metric3d_vit_small
```

## 6. Run static + geometry validation

```powershell
.\validate-v2.2.ps1
```

Expected final line:

```text
V2.2 validation PASSED.
```

## 7. Load the real models

After SAM3 checkpoint access and dependencies are ready:

```powershell
.\validate-v2.2.ps1 -SmokeModels
```

## 8. Start v2.2

```powershell
.\start-v2.2.ps1
```

Default port: `8010`.

Production v2.1 continues to use port `8000` and its existing `.venv`.

## 9. First validation rooms

Use the same images that exposed the v2.1 defects:

1. Kitchen
2. Room 2

Record for each:

- floor mask boundary
- visible floor area
- furniture occlusion accuracy
- tile perspective convergence
- physical tile scale
- grout spacing
- edge distortion
- render time

Do not compare only segmentation confidence. The acceptance criterion is the final rendered image.
